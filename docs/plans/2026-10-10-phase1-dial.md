## Core contracts v2 (change the type → tests → code → log)

**Document v2** (`document.ts`) replaces v1.
```ts
type RatioId = 'square'|'portrait'|'landscape'|'story'|'a4'|'banner';
type CompId = 'cover'|'split'|'stack'|'poster'|'frame'|'band';     // GuideId unchanged; divisions shown as "Quarters"
type Role = 'ground'|'ink'|'accent';
type RowId = 'base'|'accent'|`c${number}`;                         // c0… = custom hues (5g)
type Step = 0|1|2|3|4|5|6;                                         // lightness 92,78,64,50,36,22,10
type ColourRef = { role: Role } | { row: RowId; step: Step } | { hex: string };
type Palette = { hue: number|null; dark: boolean; custom: string[]; accent?: string };
type Frame = { rect: Rect; rot: number; fontSize?: number; hidden?: boolean };   // local to one size
type Slot = 'image'|'accent'|'headline'|'body';                                  // layout tag for 5f
type Base = { id: string; locked?: boolean; slot?: Slot; frames: Record<string, Frame> };
type TextNode  = Base & { kind: 'text'; text: string; weight: 400|700; align: 'start'|'center'|'end'; fill: ColourRef; fit?: boolean };
type ShapeNode = Base & { kind: 'shape'; shape: string; fill: ColourRef; icon?: { set: string; name: string; d: string; licence: string } };
type ImageNode = Base & { kind: 'image'; asset: string|null; cutout?: boolean; focus?: Point };   // asset null = empty frame
type InkNode   = Base & { kind: 'ink'; paths: [number, number][][]; stroke: number; fill: ColourRef; form?: 'line'|'arrow'|'rect'|'ellipse'|'tri' };
type SizeSpec = { id: string; ratio: RatioId; guide: GuideId|null; comp: CompId|null };
type KuraDoc = { version: 2; id: string; createdAt: string; palette: Palette; ground: ColourRef|null; sizes: SizeSpec[]; nodes: DocNode[] };
```
- **Linked sizes (5w) come from the structure.** Content (text, fill, weight, asset, cutout, lock) lives on the node; rect, rotation, font size and hidden live in `frames[sizeId]`. So edits carry across with no sync code. There is one shared z-order. Adding or deleting a node affects every size, and `hidden` leaves a node out of one size.
- **Dark mode (5i):** each row reference maps step `s` to `6−s`. Literal hex colours never mirror.
- **Custom hue (5g):** a pasted hex adds a `c{n}` row. The row has the 7 fixed lightness steps, and the step nearest the hex is replaced by the exact hex.
- **Ground (5z):** `ground: null` means "unfilled". The editor draws the palette ground, and export can offer "No ground".
- **Derived, never stored:** effective font size, overflow and off-canvas flags, the cover crop (computed from `focus`), physical alignment and text direction.
- **Deliberately left out:** per-size z-order, a free-crop UI, groups, per-role overrides beyond the accent, and a file manager. Icon path data is stored inline, so documents and SVG export don't depend on the icon bundle.
- **Migration:** a pure `migrate(x) → { doc, inline: {asset, dataUrl}[] }`. A v1 doc becomes one size with `comp: null`, a neutral palette and `ground: null`.
  - Colours become `{hex}`, and `left`/`right` become `start`/`end`.
  - Shapes are renamed: rectangle→rect, ellipse→circle, triangle→tri, star→star5, arrow→arrowR.
  - Each image `src` becomes asset `v1-<nodeId>`. The app writes those images to IndexedDB before saving the v2 doc.

**Snapping v2** (`snap.ts` extends the current `snap()`; all 12 existing tests stay unchanged)
```ts
type Tier = 0|1|2|3;   // guide lines, canvas edges+centre, other objects, grid
type SnapLine = { id: string; axis: 'x'|'y'; at: number; tier: Tier };
SnapInput  += { rotation?: number; extra?: SnapLine[]; reach?: number; hold?: number; held?: { x?: string; y?: string } };
SnapHit    += { what: …|'corner'; tier: Tier };
SnapResult += { held: { x?: string; y?: string }; pull: { x?: number; y?: number } };
snapLines({ canvas, others, grid?, centre }): SnapLine[];
snapAngle({ angle, canvas, regions, shift, lock, reach, hold, held }): { angle; caught: number|null };
```
- **How each axis is chosen:**
  1. If the previously held target is still within `hold`, keep it.
  2. Otherwise, among candidates within the threshold, order by tier, then |delta|, then the existing tie rules (5k).
  3. Otherwise, take the nearest candidate within `reach` and apply a soft pull of `delta·f³`, with no hit. `pull[axis]` drives the line's opacity.
- **Determinism stays:** the previous hold is an explicit input, there is no time or randomness, core never clamps, and axes stay independent.
- **Defaults:** if `reach` is unset it equals the threshold. With no `extra` lines, behaviour is exactly v1.
- **App values:** move uses lock 6, reach 20 and hold 13, in screen px divided by scale. Resize uses a hard 8 px with no pull.
- **Size candidates** come only from tier-0 lines and canvas edges.
- **Rotated nodes (5m):**
  - Move snaps the 4 rotated corners and the centre.
  - At multiples of 90°, resize follows the v1 path with remapped handles.
  - At other angles, resize gets size candidates only, in the node's local frame.
- **`snapAngle`:** targets are multiples of 45°, ± the canvas diagonal, and ± every guide-cell diagonal (3a). It locks within 3°, pulls within 11° and holds within 7°. Shift gives 15° steps.
- **Alt bypasses snapping entirely (5j);** that is handled in the app.
- **Contract changes to log (supersedes D-006):**
  - Position targets add the canvas centre, objects and the grid.
  - The winner's hits only (5k). A span hit still names both of its lines.
  - Text corner handles scale the font; e/w handles rewrap.

## App architecture

- **Store** (`app/store.ts`): holds `{doc, ui}`. `commit(doc, {key})` records history and schedules autosave. Updates are immutable, so an undo snapshot is just a reference. One rAF scheduler re-renders with dirty flags for the doc, overlay and chrome.
- **Canvas** (`app/canvas/`):
  - The renderer keeps the `render(doc, opts)` interface. Opts gains `sizeId`, `measure` and `transparent`.
  - The overlay adds rotated and multi-select boxes, the marquee, the rotate handle, the single winning snap line, the caught-angle line, re-ratio flags and the text crossing mark.
  - `tween.ts` interpolates rect, rotation and font size over 280 ms with `cubic-bezier(.2,0,.2,1)`. Autosave pauses during a tween.
- **Dial** (`app/dial/` replaces `app/wheel/`): an SVG of 4 rings. The hub is a small canvas drawn by the same renderer, from `relayout` of the current doc or from `starterNodes`.
- **Toolbar and panels** (`app/tools/toolbar.ts`, `app/tools/panels/{shapes,icons,colour,layers,grid,ratio,keys,export}.ts`): each panel is `mount(host, store) → update(state)`, and an input is never rebuilt while it has focus.
- **Sketch** lives in `app/sketch/`.
- **Exports** live in `app/export/`.
- **Background removal:** `app/tools/background.ts` is reused. It now writes a cutout asset; the original asset is never replaced.
- **Assets** (`app/assets.ts`): an IndexedDB store keyed by the SHA-256 of the bytes. It holds `{original, working, cutout?, natural}`, plus an `ImageBitmap` cache and a `gc` step.
- **Autosave:**
  - The asset write finishes before the commit that references it.
  - The doc and the last dial settings (5b) go to `localStorage` with a 500 ms debounce.
  - A missing asset renders as an empty frame.
  - The app requests `navigator.storage.persist()`.
- **Styles:** `src/style.css` is rewritten from the zip's `_ds/tokens/*` values (copied, not linked). The app waits for `document.fonts.load` before measuring and clears the measure cache when the font arrives.
- **M0 removals:** `app/study/` (including `pack.ts`), `?mode`/`?s` handling, the blank arm, and the paired JSON download.

## Risks

- **Memory:** an A4 canvas at 300 dpi is about 35 MB, and 3× landscape exceeds the 16.7 MP canvas limit on iOS. Options over `MAX_PIXELS` are disabled, export renders offscreen once and releases, and originals are decoded at the target size with `createImageBitmap` resize options.
- **Phosphor size:** the fill set is about 1.5 MB raw. A small index loads on demand and path chunks load lazily.
- **IndexedDB:** Safari private mode and eviction can lose it. A missing asset degrades to an empty frame and a toast says so.
- **SVG text:** export writes explicit tspans from our own measurement. Non-Latin text falls back to system fonts, and the export sheet says so.
- **Ink thresholds:** the prototype's thresholds were tuned in its own pixel space, so port them normalised to screen px and pin them with fixture strokes.
- **Size of the job:** about 16 sessions. Every milestone ends with green tests and HANDOFF updated, so either agent can pick up.
